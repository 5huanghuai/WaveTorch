# WaveTorch: A PyTorch-Based Modified Born Series Hemlholtz Equation Solver

**WaveTorch** is an open-source Python library built on [PyTorch](https://pytorch.org/), designed to efficiently solve the **frequency-domain Helmholtz equation** via the **Modified Born Series (MBS)** method. The implementation is directly inspired by [wavesim](https://github.com/ivovellekoop/wavesim) and aims to provide a modular, GPU-accelerated framework for both traditional simulation and deep learning workflows.

---

## 🚀 Features
- **Modular and Extensible** – Designed for easy integration into larger pipelines
- **GPU-Accelerated** – Leverages PyTorch for fast, batched computation
- **Deep Learning Compatible** – Seamless integration with ML pipelines
- **Computationally Efficient** – Optimized for large-scale inverse problems

## 📘 Example
This example simulates a wavefield generated by a point source in a homogeneous medium:
```python
import torch
from WaveTorch import SimRunner, SimSetting, PointSource, ComputeResource

# Initialize resources
compute_resource = ComputeResource(device='cpu', batch_size=1)

# Define acoustic speed field
speed = torch.ones((256, 256)) * 1500.0
speed = compute_resource(speed)

# Define a point source
src_coordinate = [{"ix": 128, "iy": 128, "value": 1.0}]
point_source = PointSource(speed.shape)
src = point_source(src_coordinate)
src = compute_resource(src)

# Define solver settings
sim_setting = SimSetting(
    energy_threshold= 1E-5,     # Relative energy threshold for stopping computation
    max_iteration=100,          # Maximum number of iterations
    freq = 500,                 # Frequency (Unit: 100KHz) 
    pixel_size = 0.15E-3,       # Spatial discretization step size (Unit: mm)
    boundary_widths=200,        # Width of the boundary layer (number of grid points per direction)
    boundary_type='ARL',        # Boundary type:
                                # 'PBL[n]': n-th order Polynomial Boundary Layer (PBL)
                                # 'ARL': Anti-Reflection Layer (ARL)
    boundary_param='kaiser3'    # Boundary parameter (Type: str | float)
                                # If boundary_type='PBL', this is the boundary strength coefficient (e.g., 0.2, 0.25)
                                # If boundary_type='ARL', this is the window function name (e.g., 'nuttall', 'kaiser3' means kaiser window with beta=3)
)
# Solve the Helmholtz equation
sim_runner = SimRunner(compute_resource, speed, sim_setting)
field = sim_runner(src)
```
